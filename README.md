# ✈️ Airport Management System (Java CLI)

[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

A **Command Line Interface (CLI)** based **Airport Management System** developed in **Java** using **Object-Oriented Programming (OOP)** and **Data Structures** concepts. The project simulates airport operations such as passenger management, flight scheduling, staff management, ticket booking, and airport administration.

---

## 📌 Features

### 👤 Passenger Module

* User Sign Up & Login Authentication
* View Flight Schedule
* Flight Ticket Booking
* Round Trip & One Way Trip
* Ticket Cancellation
* Flight Status Tracking
* Luggage Status
* User Profile Management

### 👨‍✈️ Staff Module

* Generate Boarding Pass
* View Passenger Details
* Check Luggage Status
* View Flight Status
* View All Booked Passengers

### 🛡️ Admin Module

* Hire Staff
* Fire Staff
* View Staff Members
* Create Flight Schedule
* View Scheduled Flights

### 🏢 Management Module

* Manage Staff
* Defence Staff Management
* Medical Staff Management
* Air Traffic Control (ATC) Staff Management
* Daily Income Management
* Total Revenue Tracking

## 🚀 How to Run

1. Clone the repository.
2. Open the project in **IntelliJ IDEA**, **Eclipse**, or any Java IDE.
3. Compile all Java files.
4. Run `AirportManagementSystem.java`.
5. Use the interactive CLI menu to access different modules.

---

## 📋 Functional Workflow

1. Select your role.
2. Passenger can Sign Up or Login.
3. Admin creates flight schedules.
4. Management manages airport staff and income.
5. Staff handles passengers and boarding.
6. Passengers book or cancel tickets and check flight details.
